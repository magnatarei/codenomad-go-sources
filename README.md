# 50 sources de Go da CodeNomad Academy

Este repositório reúne 50 programas completos em Go, um por pasta, prontos para rodar com `go run` e explicados onde importa. Ele serve para quem está aprendendo Go e quer ler código idiomático de verdade (structs com métodos, interfaces, slices e maps, `error` como valor de retorno, `flag`, `bufio`, `encoding/json`, `net/http`, `time`), e para quem já programa e quer uma calculadora, um validador, um organizador de pastas, um servidor HTTP ou um jogo de terminal sem instalar nada além do Go. Cada source faz uma coisa bem definida, valida a entrada, dá mensagens de erro claras e termina com três exercícios para você continuar. É um projeto da [CodeNomad Academy](https://codenomad.org), plataforma de autoestudo em desenvolvimento de software.

## Como rodar

Requisito: Go 1.22 ou mais novo. Nada além da biblioteca padrão: o [go.mod](go.mod) da raiz não declara dependência nenhuma e não há download durante a compilação. Os 50 programas foram conferidos com `go1.27.3`, `gofmt` e `go vet` limpos.

Cada source é um pacote `main` dentro de `sources/NN_nome/`. Rodar com argumentos reais, a partir da raiz do repositório:

```bash
go run ./sources/01_calculadora_juros_compostos -capital 1000 -taxa 0.8 -meses 24 -aporte 200
```

Rodar a demonstração da mesma source:

```bash
go run ./sources/01_calculadora_juros_compostos --demo
```

A flag `--demo` executa uma demonstração completa com dados de exemplo, sem pedir nada no teclado e sem acessar a internet. Ela termina sozinha em poucos segundos e é o jeito mais rápido de ver o que o programa faz antes de ler o código.

Sem argumento nenhum, o programa mostra o uso. Os jogos (46 a 50), sem argumentos, entram no modo interativo. As flags aceitam um ou dois hífens (`-demo` e `--demo` são a mesma coisa), como em todo programa que usa o pacote `flag`.

Para gerar um executável em vez de rodar na hora:

```bash
go build -o juros ./sources/01_calculadora_juros_compostos
./juros --demo
```

No Windows o arquivo gerado é `juros.exe`. Para compilar os 50 de uma vez e conferir que tudo está em ordem, `go vet ./...` e `go build ./...` a partir da raiz.

## Como este material é organizado

Um arquivo por programa. Cada source vive em `sources/NN_nome/main.go`, em que `NN` é o número de 01 a 50, e é um `package main` com a sua própria `func main`. Não há pacote compartilhado entre as pastas: você copia uma pasta e ela roda sozinha. O `go.mod` da raiz (`module codenomad/sources`, `go 1.22`) existe só para o `go run ./sources/...` funcionar sem configuração.

Cabeçalho padrão. Todo arquivo começa com o mesmo bloco de comentário `//`, antes do `package main`, com cinco campos: "O que faz", "Como usar" (o comando real com argumentos e o comando com `--demo`), "O que você aprende", "Requisitos" e a licença. Dá para saber se a source serve antes de rolar a tela.

Comentários onde importa. Os comentários estão nos pontos em que um aluno costuma tropeçar: por que dinheiro se guarda em centavos inteiros, por que o layout de data do Go é `2006-01-02`, por que a ordem de um map é aleatória, por que a fila feita com slice segura memória, quando usar `crypto/rand` em vez de `math/rand`. O resto do código fala por si.

Bloco "Para ir além". Cada arquivo termina com três exercícios sugeridos para você estender o programa com o que acabou de ler.

Só biblioteca padrão. Os 50 arquivos usam apenas o que vem com o Go: `flag` para os argumentos, `os`, `bufio` e `path/filepath` para arquivos, `encoding/json` e `encoding/csv` para dados, `net/http` para o cliente e o servidor web, `crypto/sha256` para comparar arquivos, `time` onde há espera ou medição, `sort` e `slices` para ordenar. Isso é de propósito: você aprende a linguagem, não um framework.

Erros como valores. Nenhum `panic` em caminho que dependa da entrada do usuário: a função devolve `error`, a `main` imprime "Erro: ..." e sai com código 1. Os arquivos passam em `gofmt` e `go vet` sem nenhum aviso.

Dois modos em toda source. Com argumentos, o programa faz o trabalho de verdade. Com `--demo`, ele mostra tudo o que sabe fazer sem depender de você.
